# Reverbot

Reverbot identifies music and applies audio effects. Choose the guide for the version you want to use.

- [Telegram bot](telegram-bot/README.md) — recognize tracks and receive processed audio in Telegram. Includes setup and deployment instructions.
- [Shazam Desktop for Windows](windows-app/README.md) — process local media or tracks, combine effects, and export MP3s. Includes the Windows download and setup instructions.
